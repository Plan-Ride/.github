# Plan&Ride

A transit app for Slovakia: departures of every carrier, a journey planner, and following your bus with a live notification. Made by Michal Karafa and Michal Jablonský as a student project.

- **Get the app:** [Google Play](https://play.google.com/store/apps/details?id=com.ksjd.testem)
- **Website:** [par.karafa.net](https://par.karafa.net)
- **Contact:** par@karafa.net

## Repositories

| Repository | What it is |
|---|---|
| [app](https://github.com/Plan-Ride/app) | The Android app, its Wear OS companion and the iOS project |
| [emhub](https://github.com/Plan-Ride/emhub) | The server: timetables and the planner, riders' delay reports, bug reports, the admin dashboard and the website |
| [web](https://github.com/Plan-Ride/web) | The web version, mainly for iPhones |

Found a bug? The quickest way is **Report a bug** inside the app: it sends the app's log along with your description.
